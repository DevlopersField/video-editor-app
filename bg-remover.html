How it works

This page explains exactly what happens when you drop a photo into BG Remover, and every piece of technology involved. No black boxes — the whole app is one readable HTML file you can inspect yourself.

1 You add a photo

Your image is read directly from your device into the browser's memory using the FileReader / URL.createObjectURL APIs. It is never uploaded anywhere — there is no server, no account and no API token involved at any step.

2 The AI model downloads — once

On the very first run, the app downloads a pre-trained image-segmentation model (about 40 MB) from a public CDN. After that your browser keeps it in its HTTP cache — the same place it keeps images from websites — so the app works offline and starts instantly.

  • The 💾 storage bar at the bottom of the app explains this and offers cleanup.
  • The 🗑 Delete AI model from device button clears everything the page itself can clear. Because browsers don't let a web page delete its own HTTP cache, the button also gives you the one manual step: Settings → Delete browsing data → Cached images and files.
Why "not downloaded" can be misleading: an earlier version of this bar checked the Cache Storage API — but this library keeps the model in the regular HTTP cache instead, which a page can't inspect. So the bar could say "not downloaded" even right after a successful run. It now tells you this honestly.

3 The AI finds your subject

The model looks at every pixel and decides "subject" vs "background", producing a soft transparency mask — including tricky areas like hair and fur. This runs on your device (your CPU, via WebAssembly), not on a server.

4 You refine the edges (optional)

The Refine edges panel post-processes the AI's mask with classic image math:

  • Feather — blurs the mask edge for a softer, natural cutout.
  • Expand / shrink — grows or tightens the mask by a few pixels to remove halos or recover eaten edges.

5 You export

The cutout is composited over your chosen background (transparent, white, black, blurred original, or a custom color) and saved with the canvas.toBlob() API as PNG, WebP or JPG — at full original resolution. Batch mode repeats this for every photo in the queue.

ISNet model The pre-trained neural network inside the library, trained specifically for high-accuracy subject/background segmentation.
ONNX Runtime Web The engine that executes the neural network, using WebAssembly so it runs fast without a GPU.
Cache Storage API Checked by the app's 💾 storage bar — though this particular library keeps the model in the regular HTTP cache instead, which is why the bar explains that honestly.
Canvas 2D API Draws the preview, the before/after slider, edge refinement, background compositing and the final export.
Everything else Plain HTML, CSS and JavaScript written for this app — the file you're reading right now.
Privacy in one line: the only network requests this app ever makes are downloading the open-source library and model from a public CDN. Your photos are processed locally and never transmitted anywhere. Open your browser's DevTools → Network tab and watch — you'll see for yourself.

❓ Troubleshooting

  • Stuck on "Downloading AI model": you need internet for the first run only. Check your connection and reload.
  • "Out of memory" on huge photos: the model needs RAM proportional to image size. Try a photo under ~12MP, or downscale it first.
  • Rough edges: use Feather (1–2px) and Expand/shrink (±1–3px) in the Refine panel.
  • Want your space back: the 🗑 button in the 💾 storage bar at the bottom clears what the page can clear; for a full wipe also do Settings → Delete browsing data → Cached images and files (that's where the ~40 MB model actually lives — the browser's HTTP cache).
